# Team crests for selected full leagues

Date: 2026-10-24`r`nStatus: Approved design

## Goal

Show each club's crest beside its name in match rows generated by selected full leagues, on both the launcher home screen and the screensaver. Keep the Arabic layout clear and compact.

## Current behavior

League fixture files already preserve `strHomeTeamBadge` and `strAwayTeamBadge`. The shared page renderer can cache small crest copies in local storage and fit long match rows. Crest rendering is currently gated to the launcher widget, so the screensaver match card omits crests.

## Design

- Reuse the existing badge URLs, team IDs, crest fetch and resize helpers, and local cache. Do not add a second logo provider or bundle club images into the APK.
- Enable the existing crest path whenever a page uses match data, including the screensaver match card and the launcher widget.
- Put a compact, consistently sized crest beside each club name in every eligible match row, preserving right-to-left ordering. Missing or invalid badges leave the team name visible without a broken-image mark.
- Keep the existing fit behavior: shorten names, shorten date text, and reduce text size before removing a crest when a row still cannot fit. This avoids overflow on TV layouts.
- Use the existing fixture refresh cycle and cache; no new polling loop is introduced. Refresh a crest only when its URL changes.

## Scope

Applies to league fixtures and followed-team fixtures wherever both already use the shared match renderer. Live matches and ordinary results use the same team-row treatment. No settings or league-selection behavior changes.

## Failure handling

If a badge URL is absent, malformed, unavailable, or not an image, show the club name without the crest. If local storage cannot retain a resized copy, use the original badge URL as the existing fallback. If a line is still too wide, preserve the match row and let the existing fitting logic remove the crest as its final fallback.

## Implementation validation

Build the bundled TV page and inspect the rendered match card in both launcher-widget and screensaver modes with representative league fixture data, including a missing-badge case and a long team name. Do not change the league data source or add runtime network polling.
